# Lab 5 - Recursion

# Files
- **snowflake.py** : Draws a Koch snowflake using turtle. There are two versions: one uses recursion and the other uses a stack. compare_snowflake() prints the time and memory each one uses.
- **answers.txt** : Answers for Part 1 and Part 4.

# How to run
1. Install memory_profiler: `pip install memory_profiler`
2. Run: `python Lab5/snowflake.py`
3. To change the depth, edit the second number in `KochSnowflake(500, 3)` at the bottom of the file.
