1.1.a
Both functions set up the turtle with init_turtle(), then loop 3 times.
Each time they draw one side and turn left 120 degrees, so you end up
with 3 sides like a triangle.

4.1.b
The recursive version makes a new function call every time it recurses,
and each call stays on the call stack until it finishes, so it uses more
memory. The stack version only uses one function and a list of small
tuples, so it uses less.
The times are pretty close because both draw the exact same lines and
turns, and most of the time is just the turtle drawing on the screen.
