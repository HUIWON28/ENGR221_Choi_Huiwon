[PART 1]
1.2.a  
The player's location is a list of Cell objects (self.body). The head is body[0] and the tail is body[-1].
 
1.2.b  
get_player() returns the head; get_tail() returns the tail.
 
1.2.c  
GOING_NORTH/SOUTH/EAST/WEST: the player moves one cell in that direction each turn. 
AI_MODE: the next cell is chosen automatically by the search algorithm (BFS/DFS) toward the closest duck.
 
1.2.d  
get_next_cell() returns the neighbor of the head in the current direction (None if off the board). 
get_next_cell_ai() currently returns a random neighbor of the head.

[PART 3]
 
3.2.a  
With DFS the player takes long, winding paths and often passes nearby ducks. 
DFS uses a stack, so it keeps going deep in one direction before backtracking and finds whichever duck is at the end of that path, not the closest one.
 
3.2.b  
BFS finds the shorter path. 
It uses a queue and explores cells in order of distance, so the first food it reaches is the closest one. 
DFS gives no such guarantee.
